# Обучение английскому языку

Вёрстка сайта Юлии Старовойтовой по макету дизайнера.

Вся страница целиком в одном файле — `index.html`. Ни сборщика,
ни зависимостей, ни библиотек анимации: чистые HTML, CSS и немного
JavaScript на скролл. Двадцать изображений зашиты внутрь, страница
весит 251 КБ и грузится одним запросом.

## Что свёрстано

Три экрана, все со сценарием по прокрутке.

**Первый экран.** На компьютере прилипает к окну, и скролл ведёт сюжет:
фраза «...английский можно учить только ТАК — годами, сидя за столом,
до тошноты...» набирается по словам, следом на «Фонтан» Дюшана
прилетает чёрный клочок бумаги. Всё привязано к позиции скролла —
прокрутка назад отматывает анимацию.

На телефоне тот же экран разворачивается в раскадровку из трёх тактов:
заголовок обрывается на «можно учить только», дальше набирается реплика,
затем «Фонтан» прилипает к центру и принимает бумагу. Плакат не ужат,
а перекроен: на узком экране чтение вертикальное, и диагональ
с компьютера переложена в вертикаль.

**Второй экран.** Фото, крупный заголовок с рваной разбивкой строк
из макета и полупрозрачный пакет, сквозь который просвечивает текст.

**Принципы обучения.** Заголовок висит по центру экрана, мимо проезжают
четыре цветные карточки и перекрашивают его. Вокруг плавают объекты
коллажа — рыбки, попугаи, «Оскар», — каждый со своей скоростью.

## Как сделано перекрашивание заголовка

Без режимов наложения. Замеры макета дали простое правило: цвет букв
на карточке равен её фону минус 100 по каждому каналу — совпадение
до единицы на всех четырёх карточках.

Поэтому внутри каждой карточки лежит двойник заголовка нужного цвета,
а обрезают его края самой карточки (`overflow: hidden`). Скрипт держит
двойника ровно на месте оригинала. Так эффект работает одинаково везде,
включая Safari, где `mix-blend-mode` вместе со `sticky` ведёт себя
непредсказуемо.

## Чего здесь нет

Это фрагмент, а не готовый сайт. Из макета не свёрстаны отзывы, блоки
курсов и финал. Нет шапки, меню, футера, формы записи и оплаты — их нет
и в самом макете.

Шрифт заголовков — Unbounded. В макете дизайнер использовал
Dela Gothic One; её попробовали и вернулись к Unbounded, потому что
на экране она оказалась слишком плотной. Это осознанное отступление
от макета, а не промах вёрстки.

Подпись «У вас заболит язык от общения» стоит на двух карточках
подряд — так в макете, похоже на копипасту. Оставлено как есть.

## Сборка

`index.html` собирается из исходника, написанного под публикацию
артефактом (там `<head>` подставляется автоматически):

```
powershell -ExecutionPolicy Bypass -File ../prototype/build.ps1
```

Рядом лежит `archive.ps1` — он собирает автономную копию, в которую
шрифты зашиты внутрь, чтобы страница открывалась без интернета.
