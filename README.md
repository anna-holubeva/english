# Дюшан и английский

Первый экран сайта Юлии Старовойтовой, сверстанный по макету.

Страница целиком в одном файле — `index.html`. Ни сборщика, ни зависимостей,
ни библиотек анимации: чистые HTML, CSS и немного JavaScript на скролл.

## Что здесь показано

**На десктопе** первый экран прилипает к окну, и скролл ведёт сценарий:
реплика «...учить только ТАК — годами, сидя за столом, до тошноты...»
набирается по словам, следом на «Фонтан» прилетает чёрный клочок бумаги.
Всё привязано к позиции скролла — прокрутка назад отматывает анимацию.

**На телефоне** плакат разворачивается в раскадровку из трёх тактов:
заголовок обрывается на «можно учить только», дальше набирается реплика,
затем «Фонтан» прилипает к центру экрана и принимает на себя бумагу.

## Оговорки

Это фрагмент, а не готовый сайт:

- картинки временно вырезаны из PNG-макета, поэтому мягкие — в финале нужны
  оригиналы из Figma;
- шрифт подобран на глаз (Unbounded), точный лежит в макете;
- чёрный клочок нарисован вектором, а не взят текстурой: в макете он лежит
  поверх «Фонтана» и чисто не вырезается;
- мобильной раскладки в макете нет вообще, эта — предложение.

## Сборка

`index.html` собирается скриптом `build.ps1` из исходника, написанного под
публикацию артефактом. Пересобрать:

```
powershell -ExecutionPolicy Bypass -File ../prototype/build.ps1
```
